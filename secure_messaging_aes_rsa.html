How the hybrid encryption works

What this activity demonstrates

AES (symmetric encryption): one randomly generated AES-256 key encrypts and decrypts the message. AES-GCM also detects tampering.

RSA (asymmetric encryption): the recipient's public key encrypts the AES key; only the matching private key can recover it.

Important: this is an educational single-browser demonstration. A real messaging system must securely distribute and verify public keys, protect private keys, and use authenticated transport where appropriate.
